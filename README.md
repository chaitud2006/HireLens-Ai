# HireLens AI 🚀

HireLens AI is an advanced full-stack recruitment intelligence platform that leverages Google's Gemini AI to streamline candidate evaluation, automated resume screening, and smart job-matching insights.

## 🛠️ Tech Stack

* **Frontend:** React, Vite, Modern CSS
* **Backend:** Node.js, Express.js
* **AI Engine:** Google Gemini API
* **Version Control:** Git & GitHub

## ✨ Key Features

* **AI Resume Screening:** Automatically analyzes uploaded resumes against job descriptions to compute compatibility metrics.
* **Smart Insights:** Extracts key candidate skills, experience highlights, and gap evaluations instantly using AI.
* **RESTful Backend Architecture:** Built with an Express server to handle routing, file processing, and secure communication with the Gemini API.
* **Responsive React Interface:** Dynamic single-page application built with Vite for high performance and fast development cycles.
